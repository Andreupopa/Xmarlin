# Flowdesk — база заявок на Supabase

Статический сайт работает на GitHub Pages и обращается к Supabase напрямую из браузера. Node.js и сервер для сайта не нужны.

## Подключение Supabase

1. Создайте проект в Supabase.
2. Откройте **SQL Editor**, вставьте содержимое `supabase-setup.sql` и выполните его.
3. В **Project Settings → API Keys** (или в окне **Connect**) скопируйте **Project URL** и **publishable key**. Старый ключ `anon` тоже поддерживается.
4. Настройки уже вписаны в `supabase-config.js`. В репозиторий нужно загрузить этот файл вместе с `index.html`, иначе GitHub Pages не сможет подключиться к базе. Если когда-либо замените Supabase-проект, обновите в конфигурации URL и publishable key:

   ```js
   window.FLOWDESK_SUPABASE = {
     url: "https://ваш-id-проекта.supabase.co",
     anonKey: "ваш-publishable-или-anon-ключ"
   };
   ```

5. Загрузите `index.html`, `supabase-config.js`, `supabase-setup.sql` и `README.md` в GitHub-репозиторий. Включите публикацию в **Settings → Pages** и откройте сайт по выданному адресу.

## Важно о доступе

Выбрана публичная политика: любой посетитель с адресом сайта сможет читать, добавлять, изменять, экспортировать и удалять все записи. Поэтому не храните здесь имена, телефоны, почту и другую информацию реальных клиентов. Публичный publishable/anon key можно размещать в браузере; **никогда не вставляйте сюда secret key или service_role key**.

Заявки, сохранённые раньше только в `localStorage` браузера, автоматически в Supabase не переносятся. Их можно выгрузить из прежней версии в CSV, но для загрузки CSV в Supabase потребуется отдельный импорт.
